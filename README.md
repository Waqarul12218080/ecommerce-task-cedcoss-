# 🏠 HomeNeeds - Delivery Address Manager

A React-based delivery address manager built for the HomeNeeds platform.

## Features
- View all saved delivery addresses
- Add a new address with validation
- Set a default delivery address
- Delete addresses no longer needed

## Tech Stack
- React (JSX)
- JavaScript
- Inline CSS Styles

## How to Run
1. Clone the repo
2. Install dependencies
   npm install
3. Start the app
   npm start

## File Structure
- AddressManager.jsx — Main component with all logic and styling
